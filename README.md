# RAAZE — The Art of Scent

A cinematic, scroll-driven luxury perfume brand experience.

## Overview

RAAZE is a premium fragrance website designed to transform
product presentation into an immersive visual story.

The experience combines cinematic image-sequence animation,
refined typography, elegant layouts, and smooth scroll-based
interactions to create a distinctive luxury brand identity.

## Features

- Cinematic scroll-driven image-sequence animation
- Canvas-based visual experience
- Premium luxury-inspired interface
- Smooth scroll interactions
- Responsive design for desktop and mobile
- Interactive navigation
- Brand storytelling sections
- Product presentation with immersive visuals
- Elegant typography and visual effects
- Reduced-motion support

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Canvas API
- Image Sequence Animation
- Responsive Web Design
